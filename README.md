# AIQbiz landing preview

Static preview of the AIQbiz home / sales page (AI Influencer Build Lab, Founding Edition). Not the live site.

- `index.html`: self-contained page (HTML/CSS/JS, GSAP from jsDelivr).
- `assets/`: optimized WebP images and MP4 loops of Ava Pearson and Ethan Cole (AI-generated case-study avatars).
- `assets-b64/`: base64 sources; the workflow decodes them into `assets/`.
