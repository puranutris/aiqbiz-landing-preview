# AIQbiz landing page preview

Static, noindex preview of the AI Influencer Build Lab (Founding Edition) sales page.

- Buy buttons do not take payment.
- This is not the live site at aiqbiz.com and is not a checkout.
- Search engines are asked not to index this preview (`noindex,nofollow` plus `robots.txt`).
- `index.html` is self-contained (images inlined) so the page can be opened from a raw/CDN URL.

GitHub Pages could not be turned on from this connector or from Actions: creating a Pages site returned "Resource not accessible by integration". The Actions workflow was removed so it does not keep sending failure emails.

To publish this repo on GitHub Pages yourself: Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save. The URL would be https://puranutris.github.io/aiqbiz-landing-preview/

To take this preview down: delete this repository, or unpublish GitHub Pages under Settings → Pages if you enabled it.
